# FAQ

??? question "AssertionError"
    Uh that is bad. If you get an `AssertionError` it is very likely **not** your fault but ours.
    Please open an issue [here]({{ repo_url }}/issues/new) so we can fix this 😄

??? question "No module named checktestdata"
    This error message indicates that your BAPCtools installation is broken and some dependencies are missing.
    The most likely cause is that you are using and old git based installation of BAPCtools, please reinstall it via pip(x).
